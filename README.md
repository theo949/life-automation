# Life Automation

Turns your inbox into a Trello to-do board and walks you through a daily review.

Type `/todo`. The first run sets everything up (Trello board, Google Sheet log, optional daily schedule); after that `/todo` starts your review.

Skills: todo (entry), todo-setup, todo-review, todo-review-card ("review this card"), todo-capture (`tc:`), and the helpers todo-prioritizer, todo-discovery, todo-prep.

Needs: Trello, Gmail, Google Drive and Sheets. Optional: Google Calendar. Daily schedule needs a plan with scheduled tasks. On a schedule, the morning prep also saves your daily brief, so the review can show it at once (or refresh it if you prefer). Adding a proposed task takes one move and one description update, sent together.
